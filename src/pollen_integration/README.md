# Pollen WASM wrapper prototype

[`wasm_wrapper.go`](wasm_wrapper.go) is an Extism PDK interface prototype.
Its output is **simulated**, not model generation.

The exported `run_inference` function reads JSON with `prompt`, `max_tokens` and
`temperature`. It returns a JSON error for malformed input. For parsed input,
`executeLlamaCppWasm` uppercases the prompt and appends
` (Generated by Pollen WASM Compute)`. That fixed text is part of the simulation;
the function does not load weights or call compiled llama.cpp bindings.
`max_tokens` and `temperature` do not control the simulated output.

The wrapper sends the complete JSON result through `pdk.Output()`. It does not
stream generated tokens. Compiling it requires a separately configured TinyGo
and Extism PDK build environment; compilation alone does not provide a model
engine or a qualified Pollen deployment.

The separate Architect adapter expects an externally supplied OpenAI-compatible
gateway. It does not wire this wrapper to llama.cpp. See
[Pollen/WASM prototype status](../../docs/hybrid-wasm-llm.md) for the available
helpers, gateway prerequisites and evidence needed for an inference claim.
